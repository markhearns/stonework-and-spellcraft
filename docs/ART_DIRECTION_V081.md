# v0.81 asset production notes

Thirty separate ordinary equipment icons, four completed signature variants and two feature illustrations were generated for this release. The exact shipped file hashes, dimensions, alpha flags and byte sizes are recorded in ART_V081.json. Optimized runtime files are bundled; raw generation masters are not needed to run the game.

Shared icon direction: refined coloured woodcut engraving, grounded iron/steel and ordinary cloth/leather/wood, muted parchment highlights, readable isolated silhouettes, transparent background, no border or lettering. Inventory icons are reduced to at most 256 by 256 and encoded as WebP quality 84. Hand tools, clothing and steel weapons share this direction without material rarity colours.

Signature variants: the scholar’s ash staff gains restrained reference marks; Kaede’s steel kanabo has controlled-impact marks; Sabine’s steel ward key has precise keeper’s seal marks; Nyssara’s engraving tool carries assay marks. Variants appear only when the completed signature host matches the illustrated object. Other chosen hosts retain their correct base image.

The watch-road feature shows a wet stone stair, an old watch gate and a sheltered post in the established engraved landscape style. It is 1440 by 960. The chapter feature shows familiar steel, boots and fitting tools on an inscription bench, 1280 by 720. Both are WebP quality 84. These are scenery illustrations, not diagrams of exact game mechanics.

The ordinary gauge icon was regenerated as a steel caliper and graduated rule so its silhouette matches its measuring role. Existing resident portraits, accepted art routing and wardrobe variants were not redrawn.
