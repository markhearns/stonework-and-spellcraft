Arrival

- Two choices, three branches each: your reason for coming and the first thing you notice. Choices save immediately, survive reload and use the normal revision/idempotency protections. No stat bonuses, resource changes, phase costs or path locks.
- Getting settled explains the scholar, the old castle, starting rooms/resources, research -> first lantern, living-wing facilities, conservatory, expeditions/return, resident visits/membership/work agreements, copying income, Home/This phase/Goals and explicit Advance.

Navigation and phase usability
- Go directly to lists destinations grouped by activity. Navigation is read-only.
- Mobile-width navigation is collapsed behind Navigate; choosing a destination closes it. Desktop secondary tools sit under At your desk. Sidebar scrolling keeps long menus reachable.
- Home leads with the opening action before goals and task lists. It recognizes active founder projects, paused hearth research, missing research funds and away-state travel.
- Advance labels its destination phase/day. Home and This phase show actual authoritative preview progress, forecast and paused work with links. Required field decisions expose an unavailable-button explanation instead of an unexplained failed Advance.
- Phase buttons name commitments and actions. Ready neighbour deliveries disclose exact goods and rewards. Server readiness checks still decide whether a task can execute.
- New controls use existing focus styling and explanatory disabled buttons. Arrival choices move focus to the updated content. Actual keyboard/touch behavior still needs rendered verification.
