# v0.93 — A clearer daily rhythm

This release audits all seven opening chapters and improves the decisions between milestones. Construction, expedition durations, rewards and wages stay the same.

- Home now shows evening wind-down and a rested-morning reminder with validated links to paused paid work.
- Returning-party and Rhess patrol rest buttons list exactly whose assignments will change. Choosing rest spends no phase; Advance includes sleep.
- Chapter funding guidance offers a bounded copying goal. It stops at the treasury target after a phase, accounts for ordinary costs and keeps any interrupted project progress. Home supports pausing and resuming; no purchase is automatic.
- Companion Overview shows actual location and activity alongside the existing room specialty and available invitations.
- Activity Overview alternates work and optional conversations after pending decisions. Old return notices and fulfilled earning receipts do not linger indefinitely on Home.
- Projects and Advance preview share one read-only forecast instead of computing it twice.

The two ordinary playthroughs still finish on days 90 and 92. Two additional routes with evenings off finish on days 94 and 96. See PACING_V093.md and VERIFICATION_V093.json for methods and limitations.

Schema remains 65. Old saves need no new migration; an earning plan is stored only when the player chooses one. Preserve the complete data folder when upgrading. The archive contains no live campaign data or credentials. Browser-rendered layout review remains outstanding.
