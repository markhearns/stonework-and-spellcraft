Upgrade
Extract into a new program folder, then move/copy your complete existing data directory into it while the old server is stopped. Start python server.py as before. Keep the old data backup until the upgraded save opens successfully. Using a new program folder avoids leaving obsolete files behind from earlier ZIP overlays. Do not delete data/assets: those are your accepted imports and rollback images.
