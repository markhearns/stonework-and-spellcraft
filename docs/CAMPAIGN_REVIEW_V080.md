# Opening campaign review

## Cohesion and progression

| Chapter | Purpose | Transition checked |
| --- | --- | --- |
| 1 · The First Hearth | Practical magic, first fieldwork, basic comforts and a personal welcome | The closing choice opens Chapter 2 without auto-recruiting a visitor. |
| 2 · The House Takes Shape | Archive, cultivation and commission work give the castle practical purpose | All three undertakings and the explicit shared conclusion are required for Chapter 3. Alternate undertaking order remains valid. |
| 3 · Room to Grow | Turn those facilities into a larger home with chosen sleeping places and communal/specialist rooms | Completed construction and the walkthrough lead to Chapter 4; a smithy already built here counts later. |
| 4 · Keeping the Hearth | Protect the expanded home, teach controlled defense, and connect dungeon care with separate recruitment | Capture/release, drive-away, specialist transfer and an already-established Sabine retain distinct outcomes. Recruitment remains optional. |

The sequence moves from survival and welcome to useful work, accommodation and protection. Existing construction counts toward later chapters rather than being purchased twice. No new compulsory chapter or extra reward was added during this review. Income and work still consume phases; conversational conclusions do not. The continuous routes remain solvent without test resources. This is a functional pacing review, not a human playtest of how long repetition feels.

## Findings and changes

1. Chapter 4's preservation guidance assumed the default expedition route. It now recognizes an archived method and learning already underway, including paused two-person lessons. The guide remains read-only and exposes the ordinary actions.
2. Chapter 3's action helper set `disabled` without displaying the reason. It now uses the shared disabled-action renderer.
3. Completed chapter cards accumulated on Home. Chapters 2–4 now collapse into expandable summaries with direct access to their choices and memories, matching the existing Chapter 1 treatment.

## Content and compatibility checks

- Real-action continuous routes cover both a solitary opening and a neighbour introduction, opposite Chapter 2 orders, private/shared accommodation, alternative specialist rooms, both entrance defense styles, and different Sabine outcomes.
- Existing tests exercise safe transfer, saved prior encounters, private-room recruitment, the release-key register, both personal quests, specialist scenes, room activities and saved continuity.
- All authored expedition artwork has live URLs. The 42 overview portraits retain selected-outfit mapping and accepted custom-art priority.
- The actual v0.79 archive was used to create a save with unfinished research and accepted artwork. Reopening it with the updated code preserved state and image bytes, and backup retained the image.
- No migration, save reset, new image batch or live campaign data is included.
