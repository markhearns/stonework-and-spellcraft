# Historical source archive

The v0.115 cleanup moved the obsolete imported packages formerly under `docs/source-audit/` into `stonework-and-spellcraft-source-archive-v0.115.zip`, beside the game release. That archive preserves their exact bytes and original paths, plus the new full-resolution artwork and generation prompts. These packages are not loaded by the game, tools or tests. Earlier release reports describe their original locations.

The duplicate example pack formerly at `docs/content_handoffs/dependencies/stonework-spellcraft-content-pack.zip` is also preserved there. Its identical active copy remains at [the downloadable example pack](../static/examples/stonework-spellcraft-content-pack.zip).

`CLEANUP_V115.json` lists each archived path and digest. Runtime content bundles and canonical handoff documents remain in the game.
